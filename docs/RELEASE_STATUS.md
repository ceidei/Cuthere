## 如实记录的情况

- 本次转写存在同音错字，例如把“音画”识别成其他字。Codex结合用户明确的测试指令处理；原声和原始转写保留。此版本不承诺逐字识别正确。
- Premiere的导出XML包含整个工程。验收中补充目标序列提取工具及多序列输入拒绝，避免误改首个序列。
- Premiere导入时出现默认音频效果的转换提示。Codex处理提示并检查报告，随后对实际导出的画面和声音进行对比，确认本测试的音画结果正确。复杂效果仍需单独审片。
- 本机已有medium模型缓存；本次安装新建了运行环境，未在另一台空缓存电脑上完整下载并复验。
- WorkBuddy、其他电脑、其他Premiere版本、复杂嵌套/多机位/变速/第三方效果及任意自然语言指令未由本次样例证明。既有复杂播客修改有实用记录，不等同于通用自动执行能力已覆盖。

发行包包含干净源码、安装脚本、代理说明、测试与脱敏验收摘要。实际播客、用户语音、工程、日志中的私人路径、模型权重与旧Git历史均不进入发布包。
