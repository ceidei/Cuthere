# 测试与兼容范围

当前稳定版本：**1.0.1（Windows）**。测试日期：2026-10-20。

## 测试环境

| 组件 | 已测试配置 |
|---|---|
| 操作系统 | Windows 11 Pro |
| 剪辑软件 | Adobe Premiere Pro 25.6.4 |
| Python | 3.11 |
| 智能体 | Codex 桌面应用，可执行本地命令 |
| 转写 | faster-whisper，medium 模型 |
| 测试序列 | 25 fps，视频及双声道音频 |

## 已验证项目

| 项目 | 范围 |
|---|---|
| 安装与连接 | 独立 Python 环境、Premiere 面板、录音助手与剪辑连接 |
| F8 录音 | 按住录音、松开保存，记录播放头和序列位置 |
| 自动转写 | 保存原声、中文转写与文字修订记录 |
| 意见交接 | 一条意见的批次文件通过完整性检查并由 Codex 读取 |
| 音画剪辑 | 同步删除第 5 至第 6 秒的视频与双声道音频；12 秒、300 帧变为 11 秒、275 帧 |
| 写回与核对 | 新工作工程、新序列，检查媒体、轨道、帧率与时长 |
| 导出检查 | Premiere 导出结果的画面帧数、声音及音量对比 |
| 恢复 | 面板重连与工程检查点恢复 |
| 1.0.1 界面 | 扩展名称、深色滚动条及连接状态 |

完整录音与剪辑测试使用 1.0.0；1.0.1 验证了界面、安装与连接，未重新执行完整录音剪辑测试。结构化结果见 [VALIDATION.json](../VALIDATION.json)。

自动化检查覆盖 37 项 Python 测试、6 项 Node 测试、桥接宿主契约及 6 类安装与恢复文件系统测试。运行方式见[开发与测试](DEVELOPMENT.md)。

## 已知限制

- 转写可能出现同音错字，支持回听与文字修订。
- 内置固定编辑命令覆盖普通 25 fps 序列中最长 10 秒的明确区间删除。
- 复杂意见由智能体分析并调用工具处理，需要逐项核对结果。
- 工作流测试使用已缓存的 medium 模型；空缓存下首次下载与运行尚未完成相同流程验证。
- 其他电脑、Premiere 版本、智能体，以及复杂效果、嵌套、多机位、变速和其他帧率，需要单独验证。
- 导入 XML 可能显示效果转换提示，请核对报告与受影响音视频。

使用步骤见 [README](../README.md)，故障处理见[安装与运行排查](TROUBLESHOOTING.md)。
